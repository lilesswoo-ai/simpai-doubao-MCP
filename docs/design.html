SimpAI Studio Pro

本地模型驱动的 AI 修图工作站 — 语音对话 + 人像/风光双模 + 批量同步

语音交互 人像精修 风光调色 批量处理 完全本地

一、需求特点分析

人人像修图场景

  • 核心痛点：磨皮保留质感、肤色统一、瑕疵去除、面部重塑、体型液化
  • 常用操作：磨皮 20%-30% 强度、美白牙齿、调整脸型、祛碎发、换背景
  • 批量需求：一组婚纱/写真 50-200 张，参数要统一
  • 输出要求：不穿帮、不假面、保留皮肤纹理
  • 技术方案：ReActor 换脸 + CodeFormer 修复 + Krea2/MiniMax-H3 编辑

景风光修图场景

  • 核心痛点：光影重塑、天空调色、去除杂物、局部调整、HDR 合成
  • 常用操作：压暗天空、提亮暗部、去游客、换季节、增强氛围光
  • 批量需求：一组风光片 20-50 张，风格要统一
  • 输出要求：自然、不溢出、保留云层/水面/树叶细节
  • 技术方案：Krea2 局部重绘 + ControlNet 控制结构 + LoRA 风格

六、豆包智能大脑对接流程

豆包负责智能分析和对话调参，本地 SimpAI 负责高分辨率执行。通过 MCP 双向打通。

软件
用户选了一张高分辨率人像，点"智能修图"
// 自动生成 1024px 缩略图 → 保存到临时目录
豆包
通过 MCP 读取缩略图，分析：人像照，光线偏硬，皮肤有瑕疵，背景杂乱。建议：磨皮+柔化光线+虚化背景
// MCP 工具 analyze_image → Qwen-VL 分析
我
"磨皮重一点，皮肤要自然，背景换成柔和的虚化"
// 对话调整提示词
豆包
已更新提示词，确认后用原图（6000×4000）执行
// 展示最终提示词 → 等待确认
我
"确认，开始"
// MCP 调用 → 传原图路径 → 高分辨率生成
完成
生成完成，结果已保存到 outputs-mcp 目录，软件自动刷新
// ComfyUI 8K 输出 → 软件显示对比
环节执行方说明
选图+缩略图软件用户在软件里选高分辨率原图，自动压缩到 1024px 做分析用
图片分析豆包 + Qwen-VLMCP 工具读取本地缩略图，LLM 识别人像/风光、光线、问题点
提示词生成豆包 LLM根据分析结果自动生成专业修图提示词（参考人像提示词格式）
对话调整用户 + 豆包自然语言对话调整参数，豆包实时更新提示词
确认执行MCP → ComfyUI用户确认后，MCP 传原图路径（不是缩略图）给 ComfyUI，高分辨率生成
结果回传软件生成结果保存到本地目录，软件自动刷新显示，原图/效果对比
关键设计：缩略图分析 + 原图执行
• 分析用缩略图（1024px）— Qwen-VL 处理快，省显存，足够理解内容
• 执行用原图（最高分辨率）— 保证输出质量，不损失细节
• 两者通过本地文件路径关联，不需要上传到大模型服务器
• MCP 工具接口：analyze_image(缩略图路径) → retouch_image(原图路径, 提示词)
